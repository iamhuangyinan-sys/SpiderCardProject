# 控制台命令

编辑器模式下的调试控制台，用于验证游戏逻辑。

## 命令

| 命令 | 作用 |
|---|---|
| `skip` | 跳过当前关卡（走正常收牌结算，然后弹选关） |
| `add <牌定义>` | 往发牌堆的随机位置洗入一张牌 |

两个命令都只在**卡牌场景、有进行中的对局、且不在结算收牌**时可用，否则会返回失败提示。

## 牌定义怎么写

一张牌 = 花色列表 + 点数列表 + 落牌技能 + 属性，统一用 `_` 分隔：

```
{花色}_{点数}[_{技能}[_{属性}]]
```

- **第一个下划线一定要写**，后面两段可以省略
- 每一段都可以为空（空 = 没有）

## 花色

| 字符 | 花色 |
|---|---|
| `0` | 红心 |
| `1` | 方块 |
| `2` | 黑桃 |
| `3` | 梅花 |

多个花色直接连写：`02` = 红心+黑桃。空 = 没有花色。

## 点数

| 字符 | 点数 |
|---|---|
| `1` ~ `9` | A ~ 9 |
| `0` | 10 |
| `j` / `q` / `k` | J / Q / K |
| `s` | -2：无视点数（蜘蛛） |
| `m` | -1：万能放下 |

多个点数直接连写：`0jk` = 10/J/K。空 = 没有点数。

- **点数最多 5 个（含主点数）**，超了会被拒绝
- 花色 / 点数的书写顺序随意，解析时会自动排序去重 —— 排在最前的就是主花色 / 主点数

## 落牌技能（第 3 段，可空）

| 值 | 技能 |
|---|---|
| `10001` | 回收 |
| `10002` | 复制 |

带技能的牌就是以前的「特殊牌」，整图读配表 `PlaceSkillConfig.Image`。

## 属性（第 4 段，可空）

多个属性用**分号**隔开。

| 值 | 属性 | 效果 |
|---|---|---|
| `10001` | 沉底 | 下一次发出时会发到列堆底 |
| `10002` | 毒 | 不能放入额外牌包 |

写了不存在的值会被直接拒绝。

## 示例

```
skip
add 0_1                   红心 A
add 02_0jk                红心+黑桃 的 10/J/K
add 0123_s                万能蜘蛛（四花色 + 无视点数）
add _m_10002              复制牌（无花色 + 点数 -1 + 技能 10002）
add 0123_s_10002_10002    蜘蛛 + 复制技能 + 毒
```
