# 随机关卡生成

确认初始牌组和难度时一次生成三个大关，每个大关有 7 层。每层沿分支选择一个节点，完整路线共 21 层。续玩直接恢复三张地图快照和当前大关。

选初始牌组时可以输入有符号 32 位整数种子，留空则随机生成。一个种子控制三张地图的节点、路线、关卡参数和金币奖励，地图上的复制按钮始终复制整局种子。相同种子、初始牌组张数、难度和生成器版本可复现三张地图。牌局洗牌和商店商品沿用各自的随机逻辑。

## 大关推进

- `1-1` 是唯一的教学节点，开局固定洗入一张万能蜘蛛牌。`2-1` 和 `3-1` 各有一个必经商店节点。每个大关第 7 层只有一个 Boss。
- 前两个 Boss 收牌并发放金币后打开选花色面板。玩家从未拥有的主要花色中选一个，加入两套普通 A–K 共 26 张牌，提高下一大关的花色多样性。只剩一个候选时仍需点击。加入牌组后打开下一大关地图，点击首层商店进入。三个 Boss 均跳过通关小商店。
- 最终 Boss 收牌后发放金币并保存进度，第三大关地图显示「继续」。点击后地图退场，胜利界面连背景一起淡入。胜利界面点击「返回」会删除本局存档，等淡出完成后返回主界面。点击「返回」前退出，续玩仍恢复到 `3-7` 的地图，可以再次进入胜利界面。

## 表格

关卡节点和连线由生成器生成，无需 LevelConfig 表。首关事件 11001、Boss 事件 11002 暂时写在 LevelGenerationSettings；`LevelEventConfig` 提供事件描述，`LevelTypeConfig` 提供关卡类型配置。

## 调参入口

`Assets/Scripts/GamePlay/Level/LevelGenerationSettings.cs` 集中放置难度曲线、评分系数、接龙次数权重、商店权重及奖励参数。第 2、3 大关分别提高战斗目标评分和基础金币奖励。实际列数、牌包数、接龙目标和发牌轮廓由 `LevelGenerationHelper.FillCombat` 选取。每个大关按 7 层调参，改层数时需同步阶段划分和验证代码。

普通战斗节点无开局事件，Boss 开局事件随机牌仍然随机。Boss 评分至少比本大关最难普通关高 12。接龙目标参与评分，列数和牌包沿同一大关内的路线变化不超过 1，包含相邻战斗之间穿过商店的情况。

普通战斗和 Boss 按各大关的接龙范围和候选评分抽取目标。难度参数调整在新局生成地图时生效。

地图中间层一般有 2～3 个节点。随机挑选一个保底商店层，其前一层汇合，使所有路线都获得商店选择，允许绕过商店。普通随机层以 25% 权重尝试放置商店，最多每条路线 2 个、不能连续。权重是约束前的权重，不是最终节点占比。

三个大关的中间层沿用同一套随机商店规则。固定入口商店独立于随机商店的次数和连续限制，因此第 2 层仍可出现随机商店。

Boss 前一层优先以 90% 的权重尝试生成商店，依次尝试所有候选位置，并要求至少一处前置节点可以在商店与战斗之间选择。连续商店、每条路线商店次数上限等约束仍然生效，因此实际出现率低于 90%。

生成器按 UI 居中后的实际位置限制连线：相邻层最多上下偏移一个节点间距，不跨两行，也不交叉。所有节点都可达。Boss 约束无解时，本大关最多进行 16 次确定性生成尝试。已有地图快照需重新开局才能应用新参数。

金币在生成时按评分和 ±8% 浮动确定，首关保底 120，Boss 有额外奖励。快照包含逐列发牌数、目标、奖励、事件、连线、种子和生成器版本。调整参数只影响新局。

进入关卡并完成事件后才结算实际发牌配额。牌组删减导致牌不足时，优先减少深列并保存实际配额，保持原奖励。牌数足够时不会制造空列。地图随机流与牌局洗牌、商店商品随机无关，当前不保证重新进入关卡时牌序相同。

## 难度曲线

关卡的基础目标评分和最终难度评分统一取整数。逐层插值或候选评分公式算完后四舍五入，遇到半分向上取整。难度比较和存档使用取整后的最终评分。

| 层数（难度 001） | 第 1 大关 | 第 2 大关 | 第 3 大关 |
| --- | ---: | ---: | ---: |
| 1 | 55（教学） | 商店 | 商店 |
| 2 | 90 | 132 | 194 |
| 3 | 98 | 142 | 205 |
| 4 | 106 | 152 | 215 |
| 5 | 114 | 162 | 226 |
| 6 | 122 | 172 | 236 |
| 7（Boss） | 160 | 208 | 274 |
| 普通战斗和 Boss 的接龙目标范围 | 2～5 | 4～7 | 7～10 |
| 普通战斗随机评分偏移 | −10 / 0 / +10 | −15 / 0 / +20 | −20 / 0 / +35 |
| 难度 003、004 的战斗目标评分加成 | +8 | +14 | +22 |

层数对应基础目标评分。每个普通节点按负偏移、零偏移、正偏移各 25%、55%、20% 的概率抽取一项，加到基础目标评分上。Boss 的最终评分至少比本大关最难的普通节点高 12。教学关的接龙目标为 1～2。

难度加成适用于教学关、普通战斗和 Boss。难度 003 和 004 的发牌候选都会额外尝试加入 0～6 张牌，难度 004 的通关金币按 85% 计算。

## 验证与试玩

试玩时检查普通关和商店续玩能否恢复地图和奖励。分别在前两个 Boss 收牌、等待选花色及飞牌期间退出，检查续玩只发一次金币，只加入一次所选花色，换图后只解锁首层商店。最终 Boss 通关后检查地图的「继续」、胜利界面退出后的续玩以及点击「返回」后的主界面。当前 `CardsManager.isTestMode` 默认 true，编辑器评估真实难度时应关闭测试模式。

评分只用于控制生成趋势，不保证每副洗牌可解或准确预测通关率。第一轮应重点记录牌组、种子（控制台日志）、层数、目标、通关耗时和卡住原因，再调整权重。
